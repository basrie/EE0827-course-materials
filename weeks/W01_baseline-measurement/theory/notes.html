C Programming Essentials for Embedded Systems

Pointers

A pointer stores the address of a variable, not its value.

uint32_t value = 100;
uint32_t *ptr = &value;  // ptr holds address of value
*ptr = 200;              // value is now 200

Key operations:

  • &variable = get address of variable
  • *pointer = dereference (access value at address)
  • pointer++ = increment by sizeof(*pointer) bytes

Pointer Arithmetic

When incrementing a pointer, it moves by the size of the pointed-to type:

Pointer Type ptr++ moves by
uint8_t * 1 byte
uint16_t * 2 bytes
uint32_t * 4 bytes

The volatile Keyword

Use volatile when a variable can change unexpectedly:

  • Modified by an ISR
  • Modified by DMA
  • Mapped to a hardware register
volatile uint32_t tick_count = 0;  // Modified in ISR, read in main

Without volatile, the compiler may cache the value and never see updates.

Common C Pitfalls

  1. Uninitialized variables: Always initialize before use
  2. Integer overflow: uint8_t wraps from 255 to 0
  3. NULL pointer dereference: Causes HardFault
  4. Buffer overrun: Writing past array bounds corrupts memory

Baseline Firmware Architecture

Minimal Baseline Components

  1. Clock initialization: System clock, peripheral clocks
  2. GPIO output: Trace pin for timing visibility
  3. UART: Logging and debugging
  4. Timer with interrupt: Periodic tick generation

Timer Configuration

For 1 kHz interrupt on STM32F401RE:

APB1 Timer Clock = 84 MHz
Prescaler = 8400 (register value = 8399)
Period = 10 (register value = 9)
Update Rate = 84 MHz / 8400 / 10 = 1 kHz

ISR Best Practices

Do: - Toggle trace pin for timing measurement - Set flags - Increment counters - Keep execution short (< 10 µs for 1 kHz rate)

Don’t: - Call printf or logging functions - Allocate memory - Run long loops - Block on peripheral operations

Measurement Techniques

Trace Pin Method

  1. Set GPIO HIGH at ISR entry
  2. Set GPIO LOW at ISR exit
  3. Measure with oscilloscope:
    • Pulse width = ISR execution time
    • Period = timer accuracy
    • Jitter = max(period) - min(period)

Oscilloscope Settings

  • Time scale: 500 µs/div for 1 ms period
  • Voltage: 1 V/div for 3.3V logic
  • Trigger: Rising edge, auto level
  • Measurements: Period, pulse width, frequency

USART2 Settings (Nucleo)

  • TX: PA2 (AF7)
  • RX: PA3 (AF7)
  • Default: 115200 baud, 8N1
  • Connected to ST-LINK virtual COM port

TIM2 Notes

  • 32-bit counter
  • APB1 timer (84 MHz on STM32F401)
  • Update interrupt on counter overflow
  • Remember to enable in NVIC!
